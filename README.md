# Portfolio Website

A professional and friendly portfolio website for high school students to showcase their CV, projects, courses, Ontario learning skills, and contact information.

## Features

- 📱 **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- 🎨 **Modern UI**: Clean, professional design with smooth animations
- 📚 **Multiple Sections**:
  - Home/Hero section with introduction
  - About section with Ontario learning skills
  - Projects showcase with links to demos and code
  - Technical skills display
  - Courses and education timeline
  - Contact information with social media links
- ⚡ **Interactive**: Smooth scrolling, mobile navigation, and hover effects
- 🎯 **Easy to Customize**: Simple HTML structure for easy personalization

## Getting Started

### Viewing Locally

1. Clone this repository
2. Open `index.html` in your web browser
3. That's it! No build process required.

### Customizing Your Portfolio

Edit the `index.html` file to personalize your portfolio:

1. **Replace placeholder text** with your own information:
   - Your name in the hero section
   - About me description
   - Project details (title, description, technologies, links)
   - Skills and courses
   - Contact information and social media links

2. **Update colors** (optional): Edit the CSS variables in `styles.css`:
   ```css
   :root {
       --primary-color: #4a90e2;
       --secondary-color: #50c878;
       /* ... more colors */
   }
   ```

3. **Add your projects**: Duplicate the project card structure in the HTML and fill in your own project details

## Hosting on GitHub Pages

1. Go to your repository settings on GitHub
2. Navigate to the "Pages" section
3. Under "Source", select your main branch
4. Click "Save"
5. Your portfolio will be live at `https://yourusername.github.io/Portfolio/`

## Customization Tips

- **Colors**: Change the CSS variables to match your personal brand
- **Fonts**: Replace the font-family in CSS with Google Fonts or other web fonts
- **Images**: Add profile pictures or project screenshots by adding `<img>` tags
- **Sections**: Remove or add sections as needed by modifying the HTML
- **Social Links**: Update the social media links in the contact section
